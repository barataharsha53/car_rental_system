## 🌟 Project Overview

**Car Rental System** is a modern and user-friendly mobile application developed using Flutter and Dart. It provides a convenient platform for exploring different vehicles, comparing rental categories, viewing vehicle specifications, and selecting a preferred booking date.

The application is designed to make the car selection and booking process simple, interactive, and accessible through a clean mobile interface.

## ✨ Key Features

### 🚘 Multiple Vehicle Categories
Explore four different types of vehicles:
- Sedan
- Hatchback
- SUV
- MPV

### ⭐ Flexible Rental Categories
Choose from three rental options:
- Economy Class
- Standard Class
- Premium Class

### 🚗 Vehicle Listings
- Explore different car models.
- View vehicle images.
- Compare sample daily rental prices.

### 📋 Detailed Vehicle Information
View important specifications:
- Seating capacity
- Fuel type
- Transmission
- Air conditioning
- Luggage capacity
- Mileage

### 📅 Easy Booking Experience
- Select your preferred vehicle.
- View rental details.
- Choose a booking date.
- Confirm your selection.

### ✅ Booking Confirmation
View an on-screen confirmation with the selected vehicle, rental price, and booking date.

## 🔄 Application Workflow

**SELECT VEHICLE** → **CHOOSE CATEGORY** → **EXPLORE CARS** → **VIEW DETAILS** → **SELECT DATE** → **CONFIRM BOOKING**

The application follows a simple step-by-step navigation process to provide a smooth user experience.

## 📂 Project Structure

**car_rental_system**

- **android/** – Android application configuration
- **ios/** – iOS application configuration
- **web/** – Web application configuration
- **assets/images/** – Vehicle and category images
- **lib/**
  - **main.dart** – Application entry point
  - **models/** – Vehicle data model
  - **screens/** – Application screens
    - Car Type Selection
    - Category Selection
    - Car Listing
    - Car Details
    - Booking
    - Booking Confirmation
  - **widgets/** – Reusable UI components
- **test/** – Application testing
- **pubspec.yaml** – Project configuration
